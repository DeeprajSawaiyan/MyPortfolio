## 💥 Issue #00 — The Origin Story

This is my personal portfolio, built as a **Spider-Verse-style comic book**: halftone backgrounds, speech bubbles, tilted stickers, and sound effects like *THWIP!* and *ZAP!*

I'm a **CS graduate from BIT Mesra** and a **Java full stack developer**. I build secure REST APIs with Spring Boot and Spring Security, frontends with React, and LLM-powered apps with Spring AI.

> 🕸️ *Every developer needs a costume. This one's mine.*

---

## 🗞️ What's Inside

| Panel | What you'll find |
| :-- | :-- |
| 🦸 **Hero** | Animated intro, role badges, and social links |
| 🎓 **Education & Skills** | BIT Mesra, coursework, and a sticker-wall of tech skills |
| 🚀 **Missions** | Project cards with stacks, highlights, GitHub links, and live demos |
| 📬 **Contact** | A contact form and a resume download |

### ✨ Features

- 🎨 **Custom comic theme.** Its own Tailwind palette (`spidey-red`, `spidey-cyan`, `spidey-yellow` and more), the *Bangers* display font, and hard-edged comic shadows.
- 📱 **Responsive.** Works on phones and widescreens.
- 🧭 **Smooth scrolling** navigation with a sticky navbar.
- 🧩 **Data-driven components.** Projects, skills, and social links are plain arrays, so updating the site is quick.
- ⚡ **Fast.** Vite builds it, with instant HMR in development.

## 🚀 Suit Up: Run It Locally

```bash
# 1. Clone the repo
git clone https://github.com/DeeprajSawaiyan/MyPortfolio.git
cd MyPortfolio

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

| Command | What it does |
| :-- | :-- |
| `npm run dev` | Starts the dev server with hot reload |
| `npm run build` | Builds for production into `dist/` |
| `npm run preview` | Serves the production build locally |
| `npm run lint` | Lints the codebase with ESLint |
